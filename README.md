# MSX launcher for the personal Lampa build

In Media Station X → Settings → Start Parameter → Setup:

`id:rgh:dearlordylord`

The official MSX Raw-GitHub-Redirect resolves this account's `msx` repository,
`main/start.json`. No URL shortener and no credentials are involved.
The descriptor points to https://dearlordylord.github.io/lampa/msx/menu.json.
